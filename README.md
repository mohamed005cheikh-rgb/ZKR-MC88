# 🕌 أذكار — موقع الأذكار اليومية

موقع ويب بسيط وأنيق لقراءة **الأذكار والأدعية اليومية** بطريقة مريحة وسهلة الاستخدام، مع تصميم يركز على الهدوء، الوضوح، وسهولة الوصول إلى الذكر المطلوب.

## ✨ فكرة المشروع

يهدف المشروع إلى توفير تجربة رقمية بسيطة تساعد المستخدم على قراءة أذكاره اليومية في أي وقت ومن أي جهاز، دون تعقيد أو تشتيت.

تم تصميم الموقع ليكون مناسبًا للاستخدام على:

* 💻 الحاسوب
* 📱 الهاتف
* 📟 الأجهزة اللوحية

---

## 🌙 المميزات

* 📖 عرض الأذكار بطريقة منظمة وواضحة.
* 🔢 عدّاد لتكرار الذكر.
* ⏭️ الانتقال بسهولة بين الأذكار.
* 🔍 البحث عن ذكر محدد.
* 📚 تصنيف الأذكار حسب النوع.
* 🌅 أذكار الصباح.
* 🌆 أذكار المساء.
* 😴 أذكار النوم.
* 🕌 أذكار بعد الصلاة.
* 🤲 الأدعية والأذكار المتنوعة.
* 🌙 واجهة هادئة ومريحة للقراءة.
* 📱 تصميم متجاوب مع جميع أحجام الشاشات.
* 💾 إمكانية حفظ التقدم محليًا في المتصفح.
* 🌓 دعم الوضع الداكن والفاتح.
* ⚡ يعمل بسرعة وبدون واجهة معقدة.

---

## 🗂️ أقسام الأذكار

يحتوي الموقع على مجموعة من الأقسام لتسهيل الوصول إلى المحتوى:

| القسم              | الوصف                        |
| ------------------ | ---------------------------- |
| 🌅 أذكار الصباح    | الأذكار التي تقال في الصباح  |
| 🌆 أذكار المساء    | الأذكار التي تقال في المساء  |
| 🕌 بعد الصلاة      | الأذكار بعد الصلوات المفروضة |
| 😴 أذكار النوم     | الأذكار والأدعية قبل النوم   |
| ☀️ أذكار الاستيقاظ | ما يقال عند الاستيقاظ        |
| 🤲 الأدعية         | مجموعة من الأدعية المأثورة   |
| 📖 أذكار متنوعة    | أذكار لمواقف وأوقات مختلفة   |

## 🎨 التصميم

تم بناء الواجهة مع التركيز على:

* البساطة.
* سهولة القراءة.
* الخط العربي الواضح.
* المساحات المريحة بين العناصر.
* تجربة استخدام هادئة.
* توافق كامل مع الهواتف والحواسيب.
* حركات وانتقالات بسيطة وغير مزعجة.

الهدف هو أن يشعر المستخدم أن الموقع **مساحة هادئة للذكر وليس مجرد صفحة ويب**.

## 🚀 تشغيل المشروع

لا يحتاج المشروع إلى خادم معقد.

يمكن تشغيله مباشرة عن طريق فتح:

```text
index.html
```

في المتصفح.

أو باستخدام امتداد مثل **Live Server** أثناء التطوير.

## 📱 تجربة الاستخدام

تم تصميم الموقع بحيث يستطيع المستخدم:

1. فتح الموقع.
2. اختيار قسم الأذكار.
3. اختيار الذكر.
4. قراءة الذكر بوضوح.
5. استخدام العداد لمعرفة عدد التكرارات.
6. الانتقال إلى الذكر التالي.
7. العودة إلى الأقسام في أي وقت.

## 🔒 الخصوصية

الموقع مصمم ليكون بسيطًا ويحافظ على خصوصية المستخدم.

لا يحتاج الاستخدام الأساسي إلى:

* إنشاء حساب.
* إدخال معلومات شخصية.
* تسجيل الدخول.
* إرسال بيانات المستخدم إلى خادم.

وأي بيانات محلية، مثل الإعدادات أو التقدم، يمكن تخزينها داخل المتصفح باستخدام `LocalStorage`.

## 📚 مصادر المحتوى

يجب أن تكون نصوص الأذكار والأدعية المستخدمة في الموقع **موثوقة ومراجعة بعناية**، مع الاعتماد على مصادر إسلامية معروفة وتجنب إضافة نصوص مجهولة المصدر.

> **مهم:** المشروع لا يهدف إلى إنشاء نصوص دينية جديدة، وإنما إلى تقديم الأذكار الموثوقة في واجهة رقمية سهلة الاستخدام.
