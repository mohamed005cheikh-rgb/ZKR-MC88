# 📿 ذِكر — MC88

مساحة رقمية هادئة وأنيقة تعتني بتقديم الأذكار والأدعية المأثورة من الكتاب والسنة بتجربة مستخدم مريحة للعين وبدون أي تشتيت بصري.

---

## ✨ المميزات الرئيسية

* 🎨 **4 ثيمات متناسقة:** إمكانية الاختيار بين أربعة قوالب ألوان مريحة للعين (الورقي، الزمرد، الليل، والرمال) مع حفظ التفضيل تلقائياً.
* 🔍 **بحث لحظي سريع:** محرك بحث مدمج يتيح الوصول المباشر لأي ذكر أو دعاء بمجرد كتابة الكلمة.
* 📿 **عداد تكرار تفاعلي:** زر تسبيح لكل بطاقة لحساب التكرارات مع شريط تقدم ملون وإشعار عند اكتمال الدورة.
* 📊 **إحصائيات مباشرة:** عرض تفاعلي لعدد الأقسام، إجمالي الأذكار، وعدد العناصر في القسم الحالي.
* 📱 **واجهة متجاوبة بالكامل:** تصميم سائل يعمل بكفاءة عالية على الهواتف الذكية، الألواح الرقمية، والحواسيب.
* 📚 **منهج توثيق واضح:** فصل المراجع والمصادر (حصن المسلم، كتب السنة، القرآن الكريم) في قسم خاص بأسفل الصفحة لضمان هدوء واجهة القراءة.

---

## 🛠️ التقنيات المستخدمة

* **HTML5:** بناء هيكلي مرن مع دعم كامل لاتجاه النص من اليمين إلى اليسار (`dir="rtl"`).
* **CSS3:** استخدام متقدم لمتغيرات CSS (`--variables`) لتطبيق المظاهر المتعددة، ميزة Glassmorphism، وأنظمة Layout الحديثة (`Grid` & `Flexbox`).
* **JavaScript (Vanilla):** كود نقي بدون مكتبات خارجية لإدارة الحالات، البحث اللحظي، العدادات، والأنيميشن التفاعلي عبر `IntersectionObserver`.
